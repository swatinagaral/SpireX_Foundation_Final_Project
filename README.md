# SpireX Foundation Website

A responsive and interactive website created for SpireX Foundation using HTML, CSS, and JavaScript. The website provides information about the foundation, internships, programs, services, projects, and contact details in a clean and professional interface.

## Project Overview

The SpireX Foundation website is designed to provide visitors with an easy way to:

- Learn about SpireX Foundation
- Understand its mission and vision
- Explore internship opportunities
- View internship programs and benefits
- Generate a personalized learning roadmap
- Explore programs and services
- View projects
- Contact the organization
- Read frequently asked questions

## Technologies Used

- HTML5 - Website structure
- CSS3 - Styling and responsive design
- JavaScript - Interactive features and functionality

## Main Features

### Home

The Home section contains:

- SpireX Foundation introduction
- Hero section
- Call-to-action buttons
- Organization statistics
- Why Choose SpireX section

### About

The About section provides information about:

- SpireX Foundation
- Mission
- Vision
- Core Values
- Organization Journey

Mission, Vision, and Values can be viewed using interactive tabs.

### Internship

The Internship section displays:

- Internship programs
- Program duration
- Mode
- Eligibility
- Skills
- Benefits
- Application button
- Internship process

### Learning Roadmap

Users can select:

- Area of interest
- Current skill level

The website then generates a basic learning roadmap using JavaScript.

### Programs

Visitors can explore different programs offered by SpireX Foundation.

### Services

The Services section displays the different services provided by the organization.

### Projects

The Projects section showcases sample projects and the technologies used.

### Contact

The Contact section contains:

- Email information
- LinkedIn information
- Website information
- Contact form

The contact form performs basic validation using JavaScript.

### FAQ

Frequently Asked Questions are displayed using an interactive accordion. Users can click a question to show or hide its answer.

## GitHub Workflow

This project is developed as a team project using Git and GitHub.

Each team member should:

1. Clone the repository.
2. Create their own branch.
3. Work only on their assigned section.
4. Test their changes.
5. Commit their changes.
6. Push their branch to GitHub.
7. Create a Pull Request.
8. The Team Lead reviews the changes.
9. After approval, the changes are merged into the main branch.

Example:

git checkout -b about-section

git add .

git commit -m "Added About section"

git push origin about-section

After pushing the branch, create a Pull Request on GitHub for review.

## Team Collaboration

The project uses a common HTML, CSS, and JavaScript structure so that different team members can work on different sections without affecting other members' work.

Team members are expected to:

- Work on their assigned section
- Use the common design
- Avoid modifying another member's work
- Test their own changes
- Keep their branch updated
- Create Pull Requests for their completed work
