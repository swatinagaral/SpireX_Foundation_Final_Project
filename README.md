# Internship Section — Cohort & Application Page
 ## Project Description
A responsive internship section displaying program cohorts, schedule details, key skills, benefits, an application process, and an interactive skill-roadmap generator using HTML, CSS and JavaScript.

 ## Features
 - Two cohort cards (closed batch + open batch with live registration link)
- Program schedule, key skills tags, and benefits list
- 4-step internship process with animated hover states
- Mentor support row with stacked avatars
- "Skill-Path Architect" — interactive roadmap generator (interest + skill level)
- Scroll-reveal animations on page load
- Responsive mobile layout
- No backend or database required
 ## How to Run
1. Extract the ZIP (or just download the file).
2. Open internship-section.html in Chrome, Edge or another modern browser.
3. Scroll down to see the reveal animations trigger.
4. Hover the process steps and cohort cards to see the interactive states.
5. Use the Skill-Path Architect form and click "Generate Custom Roadmap" to test it.
 ##  Technologies
HTML5, CSS3 and JavaScript.
